# Security

This project is experimental and has not undergone an independent security audit.
Do not include passwords, tickets, private keys, profile archives, server archives,
message contents or personal information in public issues.

Report suspected vulnerabilities privately to the repository maintainer using an
available private contact channel. A dedicated security inbox is not configured.
Refer to docs/E2EE_DECISION.md and docs/PROFILE_BACKUPS.md for relevant limitations.
