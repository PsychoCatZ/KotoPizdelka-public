# Локальные уведомления Android — 0.2.6

Установите APK поверх текущего приложения, сохранив данные. Откройте профиль
и внизу списка бесед включите «Уведомления». На Android 13+ появится системный
запрос POST_NOTIFICATIONS. По умолчанию настройка выключена; отказ в разрешении
не мешает переписке. Повторное открытие приложения не вызывает запрос.
Настройка сохраняется на устройстве отдельно от зашифрованного профиля.

Текст уведомления — только «Новое сообщение в КотоПизделке», без ника,
текста, номера контакта, маршрута и ключей. Используется канал «Личные сообщения»
и один заменяемый идентификатор уведомления. На экране блокировки содержимое
помечено как private. Звук и видимость можно менять в настройках Android;
вибрация приложением не включается. При выключении настройки текущее уведомление
удаляется. Нажатие открывает приложение без данных о контакте; выбор беседы
и открытие закрытого профиля остаются действиями пользователя.

Событие создаётся после сохранения нового входящего сообщения в Rust.
Если подтверждение серверу завершилось ошибкой, уже сохранённое сообщение
всё равно учитывается. Повторная доставка, загрузка истории, служебный обмен
именами и настройка приглашения не создают новых уведомлений. Если выбранная
беседа действительно видна и окно имеет фокус, её уведомление подавляется.
Открытый диалог, другой чат и список бесед не считаются просмотром сообщения.
Ошибка Android-уведомления не меняет сохранённую историю и результат доставки.

Это локальные уведомления при текущей синхронизации на экране. Фонового
опроса и push в 0.2.6 нет. Скрытие приложения останавливает новые автоматические
попытки; уже начатый запрос может завершиться и создать уведомление.
После закрытия приложение получает очередь при следующем открытии профиля
и синхронизации. Для этой версии сервер и Caddy обновлять не требуется.
Windows 0.2.6 получает общие изменения обработки входящих; системные
уведомления Windows в этот этап не входят. Схема базы остаётся v5.

## Проверка на телефоне

1. Включите уведомления и разрешите их в Android. Оставьте список бесед
   на экране, отправьте сообщение с ПК и дождитесь автосинхронизации.
2. Проверьте общий текст уведомления; нажмите на него — приложение откроется.
3. Откройте нужную беседу на телефоне и отправьте ещё одно сообщение с ПК:
   оно появится в истории без нового уведомления.
4. Повторите синхронизацию: повторного уведомления быть не должно.
5. Перезапустите клиент: настройка сохранится. Выключите уведомления —
   доставка должна продолжать работать.
6. Отказ в системном разрешении или его отзыв не должен блокировать чат.

Сборка, тесты actor/client и React-интерфейса выполнены в облаке.
Системный диалог, показ и нажатие уведомления на настоящем телефоне
проверяются пользователем после установки APK.
