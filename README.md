# КотоПизделка / KotoPizdelka-public

Экспериментальный мессенджер для Windows и Android с самостоятельным размещением relay.
Исходный код проекта распространяется под [MIT](LICENSE). Лицензии сторонних компонентов
описаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Возможности

- Зашифрованные личные беседы и локальное хранилище.
- Приглашения по ссылке и QR, аккаунты с логином и паролем без телефона и почты.
- Очереди доставки, история, непрочитанные, уведомления Android.
- Парольная переносимая резервная копия профиля.
- Клиент Windows на Tauri/React и Android с Keystore.

Это исследовательский прототип без независимого аудита безопасности.
Relay видит метаданные доставки и аккаунтов. Код знакомства нужно сверять отдельно.
Один аккаунт на нескольких активных устройствах пока не поддерживается.
Восстановленные беседы доступны для чтения; для отправки создаётся новое знакомство.

## Свой сервер

Публичная копия не подключается к серверу автора. `https://relay.example.invalid` —
намеренно неработающий пример. До сборки замените его своим HTTPS URL в
`crates/app/src/lib.rs` (`DEFAULT_RELAY`) и `apps/desktop/frontend/src/App.tsx`
(начальное значение `relay`). Оба значения должны совпадать.
Не используйте настоящие билеты, пароли или ключи в исходниках и тестах.

## Сборка и проверки

Требования: Rust 1.90+, Node.js 22.12+, npm, системный C/C++ toolchain.

```sh
cargo test --workspace --exclude kotopizdelka-desktop --locked
npm --prefix apps/desktop/frontend ci
npm --prefix apps/desktop/frontend test
npm --prefix apps/desktop/frontend run build
```
